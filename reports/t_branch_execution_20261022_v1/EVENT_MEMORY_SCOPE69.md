## 改变的机制

67表明BASE与TIME都能利用视听输入区分原人工事件内容，但60把整来源原始ASR直接加入选片仍退化。本次不训练小头、扫描阈值/提示词、追加旧失败训练剂量，改为共享同一模型的职责分离：**BASE整理局部观察，原TIME做时间选择**。
