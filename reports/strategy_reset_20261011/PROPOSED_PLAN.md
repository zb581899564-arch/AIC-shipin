# 37.66 包诊断与新提分方案

日期：2026-10-11，Asia/Taipei。状态：方案与技术债退役；未批准、未启动新实验。旧 contrast_boundary_v1 保持取消。

## 决策

主路线改为：**冻结37.66 → 分解时间与空间损失 → 优先验证裁剪尺度与联合选框 → 再处理普通片段误选和时间边界**。保持原8B，先不微调，不加大教师，不扩数据。开源教师仅作为有限的辅助对照，不能成为主路线的启动依赖。

目前不能证明空间是37.66丢分最多的一项；它排第一是因为现有实现存在明确的表达限制，且可以用较少构图参考检查，而不是因为已经获得了比赛分项真值。

## 评分决定了应优化什么

[2026-09-30官方完整赛规](https://www.aicomp.cn/wp-content/uploads/2026/09/附件1-基于视频大模型的通用视频高光剪辑算法赛题-0930.pdf)定义逐视频连续 IoU 加权 F1：

`F_video = 2 * sum(IoU of valid same-frame matches) / (N_pred + N_gt)`。

非空、有效预测场景下，可写为 `时间选择F1 * 已匹配帧平均IoU`。空视频有单独规则。最后按视频宏平均，**不能把全数据的两个均值相乘当作官网分**。多选普通帧增大分母；漏高光减少可得IoU；框的位置或宽度不对降低分子。错误frame无法跨帧补偿。

因此“更流畅”“输出更完整”“标签更多”“重要性排序更好”都不自动等于提分。当前只有总分37.66，没有可信的官方时间/空间误差分解，不能宣称丢分比例。

## 有证据的问题和仍待验证的解释

| 项目 | 证据 | 可得结论与边界 |
|---|---|---|
| 裁剪尺度表达 | 现管线让原生8B预测中心，几何阶段使用目标比例下的最大合法宽度 | 中心可以移动，宽度不能随主体变化；无法完整表达紧构图。需要实际参考判断影响大小 |
| 静态几何上限 | 已有GNMC四dev最大宽度、最佳位置的IoU上限约0.9517/0.6021/0.4985/0.9157，后三个中心best-worst=0 | 证明部分合法构图中只改中心没用。四个静态16:9样例不能外推426、9:16或官方收益 |
| 时间上下文 | 每个局部窗口至多64个原生采样帧，生成0–5段；窗口无重叠 | 动作跨窗、开始/结果不完整可能误判。采样盲区是假设，不能把约0.48秒采样间距说成模型只能输出0.48秒边界 |
| 普通段拒绝与事件取舍 | 最新银标续训锁定源macro F1增0.0198626，低于事前0.05；新NO spill、recall、UNKNOWN保守门失败 | 再加少量正例没有解决拒绝/边界问题。这是有限银标诊断，不是37.66官网误差分解 |
| 评价参考不足 | 现有裁剪弱框、自审标签与重要性分数不能当独立双比例构图/完整高光真值 | 先补一个小而可信的诊断参考，不能继续为满足配额把UNKNOWN改成NO |
| 音频未输入 | 当前视觉窗口没有音轨语义观察 | 无法据人物讲话直接认定普通片段；音频是后续候选，不宣称加入就提分 |

不重复的路线：全局缩框、仅平滑或增加锚点、继续改窗口端点、把单帧TVSum重要性阈值当比赛高光、原样重跑32B全窗蒸馏、无参考直接RL。这些没有新的质量证据；已失败版本和费用保留。

## 第一条路线：同8B增加裁剪尺度与联合选框

先做诊断，之后才决定实现。全过程不要求新教师标完整数据集。

1. 从合规非测试资料建立少量固定比较参考。优先使用已有人工构图公开标签；静态16:9只做几何筛查，视频/9:16仍需对应参考。已有弱框不能升级。若需新增有限编辑裁定，先固定来源、帧、目标比例与审核口径，只补关键缺件，不恢复96窗批量方案。
2. 在同一组高光帧上比较当前最大宽度框、最佳位置下的最大宽度上限、允许宽度变化的上限。另报告同宽度中心偏差、主体截断、字幕遮挡、镜头内抖动。目标是分清“宽度不够表达”与“模型中心判断不准”。
3. 尺度空间确有显著余量才登记一个新候选：同8B产生中心/宽度候选，在原图和候选裁切图之间评估主体完整性与构图；程序负责合法比例、边界和源坐标。保留原方案为候选，不全局乘缩放系数。只在镜头内稳定中心与尺度，不跨镜头拖框。
4. 固定时间选择、只比较空间；用来源隔离的开发/锁定参考验同帧IoU和视频macro IoU加权F1。不通过不进426。仅抖动减小而IoU无收益不能算提分。

可行性优势：正式推理仍共享原8B，不必加一个独立美学大模型；先训练0步，适配器也保持。若之后确需空间LoRA，再独立安排。当前9B只剩217,540,880参数，量化不减少参数统计，新增视觉/语音网络必须计入，不能随手加CLIP、SAM或第二个8B。

## 第二条路线：同8B的拒绝普通段与边界精修

只在诊断显示时间误差更值得处理时优先切换。冻结空间，使用完全相同原B权重。

- 原B先给候选事件，程序取事件前后的小上下文；同8B直接比较“动作准备—核心动作—结果”与普通片段，只对需要精修的边界增加观察。
- 不把候选外区域全部监督为NO；被省略不等于无高光。明确普通段与未知段分别处理，允许整窗空。
- 固定原生frame/PTS，不以标称FPS修边界。有限全局信息可能帮助查事件重复，但当前没有复核出的独立收益证据；必须作为新的受控因素，不能照搬旧global-context版本。
- 采用区间/帧级指标和事件完整性，避免仅优化长JSON的token损失。若需训练，只用明确取舍监督、边界对或可靠排序对，UNKNOWN屏蔽；保留原B负例/拒绝能力的对照。
- 普通段误选秒数、漏事件、边界偏差及UNKNOWN风险必须分别验；收益不能只由一个源或更长输出造成。

## 开源教师小对照：辅助支线

当前机器本次实际核验：RTX 6000 Ada Generation，46068 MiB可见显存；资源状态是当时快照，不是之后开训许可。

现成32B Q4_K_M与F16视觉投影器合计20,958,945,472字节。本次在Linux完整重算两文件SHA与两个运行程序SHA，全部与原下载/编译回执一致。没有加载模型。详见teacher32b_live_file_audit.json。

历史证据不利于原样重做：32B边界42调用/16事件中只有3个事件在全部上下文均形成唯一重叠事件，独立弱方向只有2个，外部弱事件macro delta为-0.1132；弱参考的覆盖/语义仍UNKNOWN。另一语义诊断12条仅3条supported，9条rejected/uncertain。同模型盲二次回答是弱一致性，不是独立真值。

所以现成32B只做接口/任务改写的低成本对照，不当默认大规模教师。如果要真正换教师，候选为[Qwen3.8-27B FP8](https://huggingface.co/Qwen/Qwen3.8-27B-FP8)：官方模型API本次返回Apache-2.0、27,781,427,952参数、仓库占用30,879,676,248字节；[模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)支持图像/视频。仓库大小不是实际峰值显存，FP8与旧GGUF接口也不是可直接替换的同一运行时。本轮不下载、不安装。

下一次获准时的最小对照：两个已有非测试难窗，仅筛事实、动作方向、边界与明确普通段；固定程序直接送原生帧和时间映射。一个混合窗，一个已出现动作方向/切点错误的窗。短JSON只给区间ID、证据帧ID、KEEP/NO/UNKNOWN与短依据，不再要求64行长事实表。记录端到端时间、首token、输入输出token、峰值显存及全部失败。超时即停，不延长到75–120分钟，不自动换提示连续补考。

两个窗只说明是否值得继续，不能证明泛化。通过后再固定一批来自不同源的比较样本，用同一学生初始权重、同训练预算对照新旧标签；仍无学生收益就结束教师支线。不得让教师标签充当自己的验证真值。

## 新实验的验收原则

本次不执行。未来执行前重新登记实际参考与输入、单一变化因素、预算及门槛；不回写旧STOP/锁定协议。现已被多轮观察的银标锁定源只能作回归，不能反复改配方后继续声称全新锁定泛化。

非测试训练/开发/锁定按原始源隔离，测试不得用于人工标注、修预测或调参。先可解释的小对照，开发有效再一次锁定评估；工程和科学均通过才做426、strict与新ZIP。没有参考不能凭总分或模型自评分补造质量PASS。不承诺50分。

优先级：尺度诊断与同8B空间候选 > 普通段/时间边界 > 有音轨样本的音频补充 > 开源教师有限对照 > 新微调/RL。实际误差分解若否定尺度机会，就转时间路线，不为坚持方案扩大投入。
