# 旧闭源标注流程退役记录

当前状态：退役并保留历史；新方向仅分析。无新AGY、豆包、教师推理、训练、426或大流量传输。

## 根因

1. 模型兼任文件调度器：读路径、view_file、观察、写事实、回读与修schema混在长Agent会话，吞吐受工具往返和上下文累积影响。
2. 结果过长：最新3个成功窗口平均204.1717秒、输出19543.3333 token；输出不等于可用监督。旧capacity_v3_network/call01实际4500.218秒后OWNED_TIMEOUT，历史另有120分钟允许值。
3. 修复层累积：逐帧/四图/联系表、bootstrap/fragment、数字/字段表示修复并存，多份runner拥有独立状态与过时接续口径。工程成功反复被误当成下一阶段入口，语义质量缺件一直存在。
4. 无效共享能力：AGY文字能回答与视频/图像批量链路可靠是不同证据；网盘Windows上传与Linux收到也是不同证据。传输与标注纠缠扩大了排查范围。

## 实际清理

- 原任务上传、独立浏览器、临时SSH隧道与子代理已经取消并停止；取消回执保留。
- 盘点6个历史目录，48份脚本/模板含AGY进程调用能力，登记SHA并在当前工作流标为RETIRED。包括旧诊断/恢复调用，不能把48说成48次真实模型调用。
- 新增唯一当前入口improvement/annotation_pipeline/control.py与policy.json：不导入旧runner，不启动子进程；闭源Agent与旧目录入口明确拒绝；当前local-direct同样拒绝，因为此轮没有执行授权。只改READY字段也不会执行模型。
- 更新AGENTS和ROADMAP最前面的当前状态，覆盖历史“继续”“自动训练/桥接”和“未下载”的接续含义。旧内容保持历史，不再作为启动指令。
- 源码、raw、失败、标签、冻结锁、旧训练和最佳包原字节保留；不删除数据/环境/模型，不修改全局AGY、浏览器、代理、SSH或Tailscale配置。

当前入口已实际验证status成功和三种拒绝路径。清单中的原脚本SHA在收尾重核，避免清理改坏冻结证据。

这是入口与维护状态的清理，不是操作系统封禁。历史脚本仍在原路径，直接调用它们可能运行旧代码，项目指引明确禁止；不能声称已物理删除全部旧程序。若将来要清磁盘或移除历史依赖，须另行确定保留范围，此轮未做。

## 后续替代原则

程序固定输入、源帧与时间戳 → 单一local-direct适配器 → 短结构化输出 → 程序校验/缓存 → 有限独立语义审核。标注服务与数据传输分开维护。先小试实际吞吐和标签价值，再按预算估算是否扩批，不承诺未经实测的速度。

新运行只保留一个可启动目录、一个状态文件；修复版本保存旧失败后登记一次迁移，不层层恢复会话。模型不获得文件搜索/终端工具；格式错误只记失败，不由模型自修多轮。UNKNOWN不转负，教师自评分不作验证真值。

删除了工作流对旧闭源Agent的依赖；尚未实现未来local-direct调用器。用户当前要求先别启动实验，不能把这份清理报告说成新教师服务已上线。
