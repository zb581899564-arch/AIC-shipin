# SumMe原始人工参考审计

2026-10-13从ETH原作者分发ZIP以严格HTTP206范围读取中央目录、README、25个MAT人工摘要和原作者MATLAB评价代码。实际只接收158673字节，无整包或视频下载；各取出成员核ZIP CRC并记录SHA。原档含25个源各自的MP4和WebM两种编码，不能称50独立视频。

原README允许标注研究使用并要求引用GygliECCV14，视频只提供非商业研究使用且作者不拥有部分原视频版权。本轮限定非商业研究开发诊断，不重新分发视频/标注，不训练新模型，不以仓库代码许可证代替媒体许可。成果报告披露出处和限制。

人工参考与比赛的共同部分是无条件摘要取舍；差异是没有裁剪框，各人工偏好并不一致。未选帧不是已证实普通，统计按所有原始摘要评审列计算平均配对F1/召回/精确率，并另外保留不同评审间差异；不能挑最有利评审作为主指标。

原MAT的user_score非0/1，正整数是人工片段编号；作者summe_evaluateSummary.m使用大于0判选中。25源的gt_score精确等于(user_score>0)的列均值。部分all_userIDs长度小于实际摘要列数，不能因此擅自删评审列；遵照作者评价函数以user_score列数为分母，并记录元数据差异。

20个源由固定字符串加源名的SHA256排序选择，前12开发、后8确认，余5预留。不依据视频内容、标签位置或新预测挑源；已查看的数据形状和标注编码须披露，不称严格从未接触的盲测。优先WebM，因为原README注明视频观察格式WebM，仍必须逐源验证原生帧数/PTS与GT映射。

不照搬原评价函数不足帧补零/多帧截断行为。原生映射不符必须停止该源，报告完整分母与缺失，不进行标签插值拉伸。所有源通过后才准入模型；冻结开发/确认和统一规则后才能读取相应模型结果。

来源：https://data.vision.ee.ethz.ch/cvl/SumMe/SumMe.zip 。原作者网页当前重定向/失效，但原作者域名ZIP实时返回HTTP200与Content-Length2396688224，HTTP范围读取完整CRC通过。第三方镜像许可证不作为本轮依据。
