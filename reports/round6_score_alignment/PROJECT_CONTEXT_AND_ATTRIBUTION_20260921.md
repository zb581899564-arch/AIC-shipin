## 一、先说结论

这次从 43.4800 提升到 43.9400，只增加了 **0.4600 分**。综合现有证据，我的判断是：

1. **首要问题是高光时间选择仍然不够准，尤其是召回和覆盖不足。**  
   新候选只预测了测试集约 **41.40%** 的帧；43.48 分旧候选预测了约 **76.20%**。两者相比，新候选删除了旧候选中的 32,705 帧，只新增 2,160 帧。P2-T2 在弱标签开发集上的提升主要来自精确率，而召回率为 0.6057，低于未微调基线的 0.6328，也低于仅供描述的 OLD_S2 0.6985。新的弱正例抽样诊断中，P2-T2 也只命中 172/272 个关键帧，少于 BASE 的 179 和 OLD_S2 的 191。  
   **这说明模型更谨慎了，但漏掉的高光很可能抵消了它减少误选和改善构图带来的收益。**

2. **P2-T2 的训练数据筛选沿用了“时空联合标签”的严格条件，导致时间模型没有用足可用的时间监督。**  
   原始训练标签有 987 条、1,417 个时间段，但 P2-T2 实际只训练 370 条。当前 518 条冻结清单要求样本同时具备 ROI、关键帧和可注入的空间映射，这对于纯时间训练过严。一次只看结构、不宣称可直接训练的扫描发现，最多有 **908 条、794 个来源组**可能具备时间训练资格，其中 335 条没有 ROI，另有 92 条属于时间映射仍需 PTS 审计的样本。  
   **目前时间模型很可能因错误继承空间准入条件而丢掉了大量时间信息。**

3. **空间构图工程已经可靠，但增量能力有限，难以单独把成绩推到 50 分。**  
   P2-Final 的新框与 43.48 旧候选在共同帧上的平均 IoU 为 **0.9384**、中位数 **0.9804**，说明两代空间结果高度相似。新候选 36,345 个框全部采用最大合法裁剪宽度，约 86.06% 来自镜头内锚点插值，只有 5,065 个帧直接调用了 Qwen。  
   Qwen 在弱正例帧上比中心裁剪有稳定优势：同一 P2-T2 时间选择下，来源组宏弱联合指标增加 **0.0814**，95% bootstrap 区间为 **[0.0429, 0.1233]**。所以空间模型不是无效；但旧候选已经使用相似的 Qwen 最大宽度框，新链路带来的空间新增收益很小。

4. **官方指标把时间与空间耦合在一起，时间漏选会直接抹掉空间收益。**  
   某帧没有被时间模型选中，该帧即使能得到很好的主体框，也不会产生任何匹配 IoU。P2-Final 在共同帧上的空间框变化不大，而时间集合明显缩小，因此“空间工程更严谨、线上只涨 0.46”并不矛盾。

5. **本次低增益不是提交格式、缺视频、越界框或解码修复失败造成的。**  
   最终包包含 174/174 个视频，0 重复、0 越界、0 非法框、0 未覆盖选中帧；ZIP 只含官方要求的 `predictions.jsonl`。首次空间推理中的 154 个解码身份失败均已在封包前修复，最终 5,065/5,065 个锚点有效。端点规则与上一轮相差约 185 帧，只占总预测量约 0.5%，不可能解释主要差距。

因此，下一轮不应继续围绕同一 82 条开发集微调参数，也不应再次替换 OraRL 或重复空间 LoRA。**优先路线应是：重新建立“只针对时间任务”的扩大训练池，完成媒体与 PTS 审计，用来源组交叉验证训练更高召回的时间模型；空间端暂时保留未微调 Qwen 作为基线。**

## 二、赛题任务和我们采用的评分理解

### 2.1 输出内容

每个测试视频需要输出若干被选中的帧及其裁剪框。输出同时回答两个问题：

- **什么时候剪：** 哪些帧属于高光；
- **画面裁哪里：** 每个被选中帧对应的主体裁剪框。

测试集共 **174 个视频**：

- 119 个目标比例为 16:9；
- 55 个目标比例为 9:16；
- 按当前测试元数据合计 87,781 帧。

### 2.2 当前掌握的官方评分形式

按现有官方文档，单视频联合指标为：

`2 × matched_frame_IoU 之和 / (预测帧数 + 真值帧数)`

其中：

- 时间上没有匹配到真值的预测帧会增加分母但没有 IoU 收益；
- 真值高光帧漏预测同样增加分母；
- 匹配帧的裁剪框 IoU 决定该帧贡献；
- 双方都为空计 1，只有一方为空计 0。

这意味着时间与空间不能分别优化后简单相加。一个空间框再好，如果对应真值高光帧没有被选中，贡献仍为 0；反之，时间选中但空间框偏离主体，也只能得到较低贡献。

### 2.3 仍未取得的官方信息

截至本报告：

- 官方 evaluator 源码仍未取得；
- 没有官方逐视频、时间分项或空间分项成绩；
- 无法看到测试真值；
- 无法精确计算“时间问题贡献多少分、空间问题贡献多少分”；
- 非法行、重复帧等极端输入在官方 evaluator 中的全部细节仍无法独立确认。

项目内部评分器只能标记为 `INTERNAL_SPEC_REIMPLEMENTATION`，不能冒充官方评分器。

## 三、官方数据、训练标签与数据身份

### 3.1 官方发布的数据

赛事方实际提供过两个下载入口：

1. 高光剪辑训练集；
2. 测试视频。

训练包中包含源视频分卷和 `train.jsonl`。没有发现赛事方另发一套“加工短片包”。此前看到的 `qvhighlights-videos` 是为修复历史媒体来源映射而取得的公开视频来源，不是赛事方独立发布的加工短片真值包。

### 3.2 原始训练标签

原始训练标签共有：

- 987 条记录；
- 1,417 个时间段；
- 624 条记录带有非空 ROI/关键帧空间信息；
- 98,242 个逐帧 ROI；
- 9,041 个关键帧；
- 所有空间标签目标比例都是 9:16；
- 空间框固定为宽 169、高 300 的教师格式。

这些标签由弱教师生成，不是人工真值。项目中统一称为：

`WEAK_TEACHER`

它们可以用于监督、比较模型与教师的一致性，但不能把弱标签 IoU 或弱标签 F1 写成真实质量，更不能直接推算官方分数。

### 3.3 源视频映射

987 条中：

- 820 条来源映射可用；
- 92 条时间映射不确定；
- 75 条缺失来源；
- 577 条同时具备可用来源映射和 ROI。

早期 640/90/88 的 train/dev/holdout 划分存在同源泄漏风险，后续按完整 YouTube 来源组重新冻结了联合弱监督划分：

| 划分 | 记录数 | 来源组数 |
|---|---:|---:|
| train | 372 | 337 |
| dev | 82 | 74 |
| holdout | 64 | 58 |
| 合计 | 518 | 469 |

该 518 条清单要求：

- 有时间段；
- 有 ROI 和关键帧；
- 时间段数不超过推理契约上限；
- 源媒体映射可用；
- clip 帧到源帧映射可注入；
- 来源组隔离。

这套条件适合时空联合诊断，却不应未经复核直接当成纯时间模型的唯一数据池。

### 3.4 新发现：时间训练池可能被不必要地缩小

本轮在不读取比赛测试内容、不启动训练的前提下，对原始 987 条标签做了结构性时间资格扫描：

| 项目 | 数量 |
|---|---:|
| 结构上可能用于纯时间任务 | 908 条 |
| 独立来源组 | 794 |
| 拟 train | 649 条 / 567 组 |
| 拟 dev | 140 条 / 124 组 |
| 拟 holdout | 119 条 / 103 组 |
| 有 ROI | 573 条 |
| 无 ROI但可能有时间监督 | 335 条 |
| 来源映射 usable | 816 条 |
| time_uncertain，需 PTS 审计 | 92 条 |
| missing source | 75 条 |
| 时间段结构非法 | 3 条 |
| 超过 5 段 | 1 条 |

该结果只能标记为：

`STRUCTURALLY_ELIGIBLE_TEMPORAL_ONLY_PENDING_PTS_AUDIT`

它不代表 908 条已经可以直接训练。92 条时间不确定样本以及所有新纳入样本都必须重新核对：

- 媒体身份；
- clip 起点；
- 容器 PTS；
- 帧序与秒数的转换；
- 来源组是否真正隔离。

此外，`temporal_pool_opportunity.json` 已经列出了这 908 条记录及初步 split 字段，因此其中的 119 条“拟 holdout”不能再称为盲留出。后续若采用这批数据，只能把切分冻结为 `FIXED_WEAK_DIAGNOSTIC_ONLY`，或者使用预先登记的来源组交叉验证；不能声称得到了新的人工盲测集。

但它证明了一项重要设计问题：**P2-T/P2-T2 的纯时间训练沿用了空间标签的筛选门，370 条训练记录可能只是可用时间监督的一部分。**

## 五、各阶段做过什么、得到了什么

### 5.1 数据对齐与第五轮

早期工作的重点是把短片标签、源视频和来源组重新对齐，修复 train/dev 泄漏，并建立弱监督清单。第五轮虽然改进了时序输出，但空间端大量复用旧框：

- 40,568 个预测帧；
- 37,325 帧使用同帧旧框；
- 3,243 帧使用“最近旧框”复制；
- 被复制框的距离中位约 25.2 秒，P90 约 108.3 秒，最大约 131 秒；
- 95.7% 的复制来自旧空间覆盖区边缘。

因此第五轮解决了一部分“什么时候剪”，却没有为新选中的时间区间真正补齐同帧空间预测。

### 5.2 OraRL 四轮调查

OraRL/Video-ORA 路线经过协议、合成真值、公开图片和弱标签对照：

- 跟踪输出经常把初始化框原样复制；
- 在精确运动合成真值上不优于固定首帧框；
- 逐帧独立空间定位有位置响应，但小目标尺度偏大；
- RefCOCO 小样本说明图片定位接口有效，但不能代表 AIC；
- 在固定弱代理对照中，OraRL 直接定位和“描述+定位”均落后当前 Qwen 基线，且抖动更大。

结论：**OraRL 不适合直接接管当前裁剪链路。** 若没有新假设和独立真值，不应重复前四轮实验。

### 5.3 空间 LoRA 小试验

固定 16 个训练来源组、最多 20 个优化步的空间 LoRA 结果：

| 模型 | 开发弱 IoU |
|---|---:|
| 中心最大合法裁剪 | 0.64969 |
| 未微调 Qwen3-VL | 0.75072 |
| 空间 LoRA 小试 | 0.73757 |

LoRA 相对未微调模型：

- 差值 -0.01315；
- 95% 配对区间约 [-0.04204, 0.00990]。

未通过训练门，完整空间训练被停止。当前保留未微调 Qwen 作为空间基线是有证据支持的决定。

### 5.4 P1/P2 空间覆盖工程

## 八、归因判断：证据等级与置信度

### 8.1 第一主因：时间选择过窄、弱正例召回不足

**置信度：中高。** 时间集合收缩和非测试召回证据很强，但官方没有提供逐视频或时间分项，因此不能把它升级为已直接观测的官方主因。

证据链：

- 测试预测覆盖从 43.48 候选的 76.20% 降到 41.40%；
- 新候选相对旧候选删除 32,705 帧，只新增 2,160 帧；
- 130/174 个视频的新时间集合是旧候选子集；
- P2-T2 开发召回 0.6057，低于 BASE 0.6328；
- 弱正例命中 172/272，低于 BASE 179 和 OLD_S2 191；
- P2-T2+QWEN 相对 BASE+QWEN 的弱正例联合增量区间跨 0；
- 线上只增加 0.46，与“更高精确率但损失召回”的预期相符。

不能据此断言 43.48 候选的所有额外帧都是真高光。它可能也包含很多假阳性。但当前证据表明 P2-T2 的收缩幅度大，而非测试证据没有证明这次收缩在联合指标上是最优的。

### 8.2 第二主因：时间训练池被空间准入条件压缩

**置信度：中高。**

证据链：

- 原始 987 条全部有时间段；
- P2-T2 只训练 370 条；
- 当前联合清单要求 ROI 和可注入空间映射；
- 初步发现 908 条可能具备纯时间结构资格，其中 335 条没有 ROI；
- 时间任务本身不需要 ROI；
- 当前模型仍在召回上偏弱。

限制：

- 908 条尚未经过完整 PTS 和媒体身份审核；
- 不能保证扩大数据后一定提升；
- 仍需来源组冻结和交叉验证，防止把错误标签量变成更大的噪声。

### 8.3 第三主因：空间模型相对旧候选缺乏足够新增能力

**置信度：中高。**

证据链：

- 共同帧新旧框平均 IoU 0.9384、中位数 0.9804；
- 全部采用最大合法宽度，尺度自由度没有被使用；
- 86.06% 的框由锚点插值产生；
- 训练弱空间标签全部为 9:16 固定 169×300；
- 测试集 68.4% 是 16:9，训练标签无法直接验证其构图偏好；
- 空间 LoRA 小试低于未微调 Qwen；
- OraRL 替换也已失败。

这不是说空间链“无用”。它修复了第五轮不可接受的远距离旧框复制，且 Qwen 明显优于中心裁剪。问题是：**旧 43.48 候选本身已经采用相似 Qwen 最大宽度框，新链路主要增加了可追溯性和工程正确性，而非显著提高构图能力。**

### 8.4 第四因素：训练目标与官方联合指标仍存在代理偏差

**置信度：中等。**

目前训练和模型选择依赖：

- 弱教师时间段；
- 弱教师 9:16 空间框；
- 来源组宏 F1；
- 弱标签 IoU。

官方评价却是时间匹配与空间 IoU 的联合值，而且测试集包含 16:9 与 9:16。弱标签教师可能与官方真值在以下方面不一致：

- 高光片段长短；
- 多段高光数量；
- 高光边界；
- 主体选择；
- 横屏构图；
- 动态尺度；
- 镜头切换附近的处理。

43.9400 证明开发弱指标上涨没有一比一转化为官方收益，但没有逐视频官方分项，无法判断具体偏差集中在哪类视频。

### 8.5 交互因素：时间漏选会抵消空间改善

**置信度：高。**

这是指标公式的直接结果。P2-Final 空间端比第五轮更可靠，但如果时间模型没有选中相应真值帧，空间改善不会计分。共同帧的框又与 43.48 候选高度相似，因此大幅删帧后的净收益只剩 0.46 是合理现象。

## 十三、建议的下一轮路线

### 路线优先级

**推荐优先做“扩大并审计纯时间训练池”，暂时冻结空间模型。**

理由：

- 当前最强证据指向时间召回不足；
- 有最多 908 条潜在时间监督，明显多于当前 370 条训练记录；
- 未微调 Qwen 空间端已有稳定弱证据；
- 空间 LoRA 和 OraRL 都已经失败；
- 剩余 GPU 预算有限，应把算力用在最可能改变时间选择的实验上。

### R7-A：纯时间数据审计，CPU 为主

1. 从 987 条原始标签重新建立纯时间资格规则，不要求 ROI。
2. 对 908 条候选逐一核对媒体身份、clip 起点、容器 PTS 和时间段范围。
3. 明确处理 92 条 `time_uncertain`：
   - 能用 PTS 确证的纳入；
   - 无法确证的保留失败记录并排除；
   - 不用人工观看测试视频补规则。
4. 按 YouTube 来源组冻结 train/dev/固定弱诊断切分；所有标签和初步 split 已暴露，明确不得称为盲留出。
5. 在看任何模型输出前固定清单和哈希。
6. 建立 5 折来源组交叉验证，避免继续围绕同一 82 条开发集调参。

**停止条件：**

- 媒体身份或 PTS 无法批量可靠确认；
- 新增样本大部分存在时间漂移；
- 来源组隔离无法保证。

### R7-B：高召回时间模型

1. 以 P2-T2 为起点，只改变数据池和预先登记的训练配置。
2. 同时报告：
   - 来源组宏 F1；
   - precision；
   - recall；
   - 预测覆盖率；
   - 多段样本表现；
   - 长短视频分层；
   - 1/3/5 段分层；
   - 合法率和空预测率。
3. 不以单个 fold 的最高 checkpoint 作为最终模型。
4. 预先冻结一个 coverage envelope，防止得到另一个过度收缩的模型。
5. 选择标准不能只看 F1；要求召回不低于基线，并在来源组交叉验证中稳定。

建议的非测试门：

- 相对 P2-T2 的来源组宏 F1 提升；
- 召回不低于 BASE；
- 多折中大多数 fold 改善；
- 10,000 次来源组 bootstrap 下界大于 0；
- 合法率保持 100%；
- 不通过改阈值追逐同一开发集。

短期：

- 继续使用未微调 Qwen；
- 保留镜头门和来源追溯；

3. 必须补一套独立 16:9 与 9:16 构图参考；
4. 单独验证动态尺度、快速运动和切镜；
5. 比较逐帧定位、稀疏锚点和插值的真实误差；
6. 只有非测试联合指标改善后才替换 Qwen 基线。

### R7-D：新的联合候选门

新的比赛候选只应在以下条件同时满足后生成：

- 完整非测试联合诊断相对当前 P2-T2+Qwen 至少提高预登记阈值；

## 十四、可供决策的三种方案

### 方案 A：时间优先，推荐

先完成 908 条潜在时间池的 PTS 审计和来源组交叉验证，再训练一个更高召回的时间模型，空间保持当前 Qwen。

**优点：**

- 直接命中当前最强证据；
- 不依赖新的外部许可；
- 最大化利用已有官方训练标签；
- GPU 成本可控。

**风险：**

- 弱教师时间标签可能与官方真值仍有偏差；
- 扩大数据也可能扩大噪声；
- 需要严格 PTS 审计。

### 方案 B：先补空间真值

暂缓训练，组织一套合法、独立、同时覆盖 16:9/9:16 的构图参考，再决定是否训练空间模型。

**优点：**

- 能解决空间方向长期缺乏真值的问题；
- 能判断最大宽度和插值是否真的合理。

**风险：**

- 数据来源和许可困难；
- 周期较长；
- 用户已决定不联系 LIVE-YT 作者。

### 方案 C：继续小步线上试分

修改时间阈值或覆盖率后重新打包提交。

**不推荐。**

原因是缺少测试真值和官方分项，继续使用排行榜选阈值会产生测试集过拟合，且当前已有证据表明问题不是一个简单端点或格式参数。

## 十五、最终判断

P2-Final 没有“工程失败”。相反，它是目前第一个在 174 条测试视频上满足以下条件的完整候选：

- 冻结时间模型；
- 同帧可追溯空间锚点；
- 镜头内有界传播；
- 无旧框长距离复制；
- 无弱标签注入；
- 无静默回退；
- 格式完整；
- 可复现封包。

它的 43.9400 告诉我们，**工程正确性已经不再是主要瓶颈，模型和监督的任务对齐才是。**

最值得修正的具体错误不是“再换一个更强视觉大模型”，而是：

> 纯时间模型错误继承了空间标签的准入条件，只使用了 370 条训练记录；随后模型在开发集上以更高精确率换取了更低召回，并在测试集上把预测覆盖从 76.20% 收缩到 41.40%。空间端虽然更可靠，但与旧候选高度相似，无法补偿漏掉的高光帧。

下一步应先把纯时间训练数据和验证制度重建好，再考虑一次新的训练。这个方向最符合现有证据，也最有机会用剩余预算产生实质变化。
