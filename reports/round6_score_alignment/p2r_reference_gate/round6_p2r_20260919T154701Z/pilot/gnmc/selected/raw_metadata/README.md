# The Gracenote Multi-Crop (GNMC) dataset

We present the Gracenote Multi-Crop (GNMC) dataset, to further research in algorithms for automatic image cropping. The dataset consists of a diverse collection of 10K images, each cropped in five different aspect ratios. GNMC is larger than existing datasets commonly used to benchmark image cropping approaches such as FCDB (1743 images) and FLMS (500 images), and can enable algorithms as described in by Christensen and Vartakavi (see below).

This file will be updated as more information about the dataset becomes available.

C. L. Christensen and A. Vartakavi, "An Experience-Based Direct Generation Approach to Automatic Image Cropping," in IEEE Access, vol. 9, pp. 107600-107610, 2021, doi: 10.1109/ACCESS.2021.3100816.
