# R7 纯时间监督池实验报告

## 最终结论

最终状态：**`STOP_KEEP_P2T2`**。

R7 完成了 908 条候选的 PTS 与身份审计、来源隔离冻结、5 步冒烟、120 步正式训练，以及冻结开发集的 BASE / P2-T2 / R7 三臂评测。R7 在 96 个开发来源组上的宏 F1 为 **0.625101**，P2-T2 为 **0.626936**；差值 **-0.001835**，10,000 次固定种子来源组配对 bootstrap 95% 区间为 **[-0.042632, 0.038771]**。R7 没有达到预先冻结的 +0.03 门槛，区间下界也不大于 0，召回率还从 P2-T2 的 0.707980 降至 0.672882。

因此严格停止：不运行确认集，不打开比赛测试集，不生成候选、不打包、不上传。继续保留 P2-T2 作为当前时序组件。这里全部指标都是 `MODEL_UNSEEN_FIXED_WEAK_DIAGNOSTIC_NOT_OFFICIAL_SCORE`，不是官方成绩。

## 结论解释

扩大纯时间监督确实把模型从 BASE 的低合法率与低 F1 提升到接近 P2-T2，但没有超过 P2-T2。R7 更偏精确、覆盖更保守：precision 上升而 recall 下降，最终 F1 持平略低。证据不支持用 R7 替换 P2-T2，也不支持继续在同一开发集上调阈值或挑 checkpoint。

下一步应回到新的、预先冻结的假设：如果继续时间路线，应优先研究稠密时间打分或显式召回建模，并使用新的非测试诊断协议；不得把本轮失败转化为对测试集的后验调参。
