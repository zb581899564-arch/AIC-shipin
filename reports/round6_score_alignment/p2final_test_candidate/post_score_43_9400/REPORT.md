## 结论

相对已确认的 43.4800，本次只提高 **0.4600**。现有证据最支持的解释是：**P2-T2 把时间预测大幅收窄，可能减少了假阳性，但同时损失了大量真实高光召回；空间侧与旧候选又非常相似，无法提供足够的新收益补偿时间召回损失。**

这不是格式或打包失败。提交已被官方正常评分，候选此前两套严格校验均为 0 issue。没有官方逐视频分项或测试真值，因此不能精确计算“时间损失多少、空间收益多少”；下述结论是对候选输出的可复现差异分析。

## 直接证据

### 1. 时间选择比 43.4800 候选激进得多

| 候选 | 预测帧数 | 占测试集 87,781 帧 |
|---|---:|---:|
| 43.4800 LoRA reader | 66,890 | 76.20% |
| 第五轮候选 | 40,568 | 46.22% |
| P2-Final 43.9400 | 36,345 | 41.40% |

P2-Final 与 43.4800 候选只有 34,185 个共同预测帧；P2-Final 新增 2,160 帧，却移除旧候选 32,705 帧。两者帧集合的 micro F1 为 0.6623，视频宏 F1 为 0.6883。174 个视频中有 130 个视频的 P2-Final 帧集合是旧候选的子集。

按画幅看同样明显：

- 16:9：P2-Final 24,190 帧，旧候选 42,528 帧；共同 23,429，旧候选独有 19,099；
- 9:16：P2-Final 12,155 帧，旧候选 24,362 帧；共同 10,756，旧候选独有 13,606。

官方联合指标可写成“时间帧集合 F1 × 匹配帧平均空间 IoU”（常规非空、合法情况下）。因此，只要被移除帧里包含真实高光，召回损失会直接降低联合分。

### 2. 空间框没有产生足够大的新变化

在两份候选共同预测的 34,185 帧上，新旧框的平均 IoU 为 **0.9384**，中位数 **0.9804**，31.92% 的框逐值完全相同。它们并非完全一样，但空间几何高度接近，无法期待仅靠这些变化稳定增加六七分。

P2-Final 的 36,345 帧中只有 5,065 帧直接调用 Qwen，另外 31,280 帧来自镜头内线性插值，插值比例 **86.06%**。全部预测都使用最大合法裁剪宽度；80.50% 的框在横向中心 5% 范围内，66.06% 在纵向中心 5% 范围内。该空间链更像“最大窗口的一维平移与平滑”，对缩放、快速主体运动、多主体切换和构图意图的表达能力有限。

P2-J 在开发切片上证明的是插值相对逐帧 Qwen 的工程保真度，不是相对人工真值的构图精度。之前已有结论也明确指出 16:9 人工构图参考不足，因此空间组件从未获得能支持显著官方提分的真实质量证据。

### 3. P2-T2 的开发提升发生在弱标签上

P2-T2 在来源隔离的弱开发标签上比 BASE 提高 0.1035，但这些标签是 `WEAK_TEACHER`，并非官方人工真值。它在相同开发集上仍低于历史 OLD_S2：P2-T2 来源组宏 F1 为 0.5497，OLD_S2 为 0.6015。OLD_S2 存在历史曝光，不能当作干净泛化成绩，但这个结果已经提示 P2-T2 并不是一个明显更强的时间定位器。

监督分布也不完整：冻结弱空间标签全为 9:16，而测试元数据有 119/174 个 16:9 视频。弱标签开发门通过只能证明“更符合当前弱教师”，不能保证更符合官方测试高光定义。

### 4. 不是主要原因的项目

- `ceil + [start,end)` 与第五轮端点差异只有约 185 帧量级，远小于新旧候选数万帧的集合差异；
- 154 个解码身份失败已在模型调用前被拦截并全部定向修复，最终 5,065/5,065 锚点有效；
- 最终文件 174 行，0 缺失、0 重复、0 越界、0 非法框，官方也已正常给分；
- 因此没有证据把 43.9400 归因于打包、帧号越界或解码修复失败。

## 下一步决策

不应继续在同一 82 条弱开发集上延长 P2-T2 训练，也不应根据这一次测试成绩直接调覆盖率。更合理的顺序是：

1. 在非测试数据上建立四臂联合归因：旧时间+旧空间、P2-T2 时间+旧空间、旧时间+新空间、P2-T2 时间+新空间。固定来源组与评分规则，明确是哪一臂退化。
2. 时序侧优先解决召回和区间边界。使用来源组交叉验证而非单一弱 dev，报告 coverage、precision、recall、零交集和多区间结果；不能只盯宏 F1。
3. 空间侧停止把“稀疏 Qwen + 86% 插值”当成提分主线。利用官方训练 ROI 训练任务特定的中心轨迹/镜头内裁剪模型，并单独补足 16:9 非测试参考；若仍只有最大宽度标签，就明确只学习中心轨迹，不声称学会尺度。
4. 下一份候选必须在非测试联合参考上显示至少 5 个百分点的联合增益、来源组 bootstrap 下界大于 0，并且 16:9 与 9:16 都不明显退化，才值得再次提交。
