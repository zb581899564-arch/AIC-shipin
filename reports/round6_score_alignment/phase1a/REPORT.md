### 2.2 评分接口：校验与数学分离（任务 2）

| 场景 | 行为 |
|---|---|
| 严格校验失败（bool 帧、NaN、越界框、缺行、坏 JSON、非对象行） | `INVALID_INPUT`，`score=null`，逐条 issue（错误码来自 vendored 校验器），**不清洗、不剔除后重算** |
| 无参考 | `NOT_COMPUTABLE`，理由写明“不得把缺失真值当作空真值” |
| 参考不全（缺视频/多余视频） | `NOT_COMPUTABLE`，列出缺失与多余 ID |
| 稀疏空间参考 | `SPARSE_DIAGNOSTIC`，只输出稀疏帧诊断，**不产出全视频联合分** |
| 完整参考 | `OK`：`F=2ΣIoU/(N_pred+N_gt)`，双空=1、单空=0，按索引视频等权平均 ×100 |

- 重复帧：**全部计入 `N_pred`，仅首个有效框贡献 IoU**（与既有实现一致，已交叉校验）。
- 结果同时给出宏平均与**帧微平均**（仅为暴露差异，不作主口径）、匹配帧平均 IoU、覆盖率、空预测率、逐视频明细。
- 与既有实现的交叉校验：在 4 个手算用例上，新实现与 vendored `internal_metric` 的分数一致（差异 0，`places=4`）。

### 2.3 唯一时间转换模块（任务 3）

`aic6/timebase.py` 是唯一实现秒↔帧转换的地方，三种约定并列且显式命名：

- `TIMESTAMP_HALFOPEN`（新内部策略）：帧 f 被选中当且仅当 `a <= f/fps < b`；合法帧 `0..N-1`；**局部时间先换到真实采样起点帧** `ceil(window_start*fps)`，而不是标称窗口起点；`EPS=1e-9` 只用于浮点表示容差。
- `LEGACY_CEIL_HALFOPEN`：`ceil(a*fps-eps)..ceil(b*fps-eps)-1`（43.48 链路），仅重放用。
- `LEGACY_ROUND_INCLUSIVE`：`round(a*fps)..round(b*fps)` 闭区间（第五轮合成器），仅重放用。
- VFR：**必须显式提供 PTS**，否则抛 `VfrRequiresPts`；无 PTS 不声称支持 VFR；PTS 需单调、有限。
- 模式选择由调用方显式传入，**不依据任何未知真值选择模式**；本模块不修改任何包。

### 2.4 三态贯通与提示词（任务 4）

- `VALID_NONEMPTY` / `VALID_EMPTY` / `INVALID(reasons)` 在解析、合成、评分三处贯通；`VALID_EMPTY` 是**可用预测**。
- 提示词由 `build_prompt(duration_sec, constraint)` 单点生成，**训练与推理共用**，段数由一个 `SegmentConstraint` 配置；`min_segments=0` 时提示词显式给出空集示例，`min_segments>0` 时不出现空集示例。
- 空结果保持空；`INVALID` 保持失败（`run_p1a.py` 在有失败测试或哈希漂移时返回非 0 退出码），**不转成空、也不转成中心 80%**。
- 历史“中心 80% 回退”只存在于 `legacy_replay` 模式且需显式开关（默认开，仅用于历史复算）。
- 1 条 7 段标签**不截断、不拼接**：`check_label_cardinality` 只报告 `REPORTED_UNCHANGED` 并保留行字节（单测断言输入未被修改）。

### 2.5 新合成接口的空间可追溯性（任务 5）

- 逐帧 provenance：`SOURCE_SAME_FRAME` / `SOURCE_SHOT_INTERPOLATION` / `NEEDS_SPATIAL_INFERENCE`（另有仅重放用的 `SOURCE_LEGACY_NEAREST`）。
- 镜头是**输入**（`ShotMap` 按视频声明 `[start,end)`），本模块**不实现镜头检测**，行为只用合成样例测试。

- 不使用任何从本轮测试统计拟合出的距离阈值（协议里写死 30 帧仅作演示性声明，见 §4）。
- 本模块不产出提交格式文件：输出 schema 为 `aic6_composition_report_v1`。

- 本轮的 40,384 / 40,568 / 3,200 / 2,747 等都是**结构性计数**；它们不构成对官方分数的预测、上界或因果解释。
