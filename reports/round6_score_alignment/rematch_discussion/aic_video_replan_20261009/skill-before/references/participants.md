# 固定参与席位与路由

这张表保存用户指定的席位，不表示当前账户一定提供这些型号。每次运行均须实时确认；不得把名称自行翻译成另一个模型。

| 席位 | 默认浏览器/网页 | 模型与作用 |
| --- | --- | --- |
| 主控 | 调用 skill 的当前 AI | 正式参与讨论、整理完整信息包、主持与必要时兜底；地位仅次于 Pro |
| Pro | Google Chrome / ChatGPT 网页的既有“研究”项目 | 先进入并确认“研究”项目，再在项目内开始或继续本任务 Pro 对话；用户指定的 Pro，最终技术顾问；每个连续决策任务最多三次，浏览器与 computer use 路由不可改 |
| Tibo 之父 | Google Chrome / 用户指定的 Dot 对话 | 保留原固定参与者与其知识上下文；不把昵称当成已确认的基础模型型号 |
| 5.6 sol | Microsoft Edge / ChatGPT 新对话或本任务专用对话 | 5.6 sol，高模式；不能因为页面显示“高”就自行认定模型名 |
| Grok | Microsoft Edge / https://grok.com/ | Expert 模式 |
| Gemini | 默认 Google Chrome / https://gemini.google.com/app | 3.8 Flash，扩展模式；替换原 Sider Opus 5.5 席位 |

Gemini 的默认浏览器可按用户当前指定调整，但指定型号/模式不能静默替换。Pro 的 Chrome 限制绝不可改。

## 身份与送达证明

ledger.json 对每席记录：指定浏览器、实际 URL/对话名、要求的型号和模式、可见核验结果（或用户明确确认）、当前轮次、上传文件名/字节/SHA、附件处理状态、发送状态、回复开始与完成状态、回复保存位置。Pro 另记实际项目名、“研究”项目 URL、会话项目归属的 UI 核验结果；不能仅因会话 URL 类似历史入口就认定归属。

模型的自称、截图旧型号和上一轮登录成功均不证明本次身份。若不能上传 MD，本轮该席位记为阻塞；只有用户明确允许改变参与名单才能以较少席位继续，不能悄悄换成口头摘要。
