二、本席位首轮自我纠错与事实校准

核对主控专项复核意见后，本席位全面纠正首轮（r00）中的事实与口径错误：

LoRA 参数量严重算错：首轮称 q_proj+v_proj 的 rank-16 LoRA 约 35M。查验 Qwen3-VL-8B-Instruct 官方 config.json（36 层、hidden 4096、32 heads、8 KV heads、head_dim 128）：

仅对 q,v 加 LoRA：36×16×[(4096+4096)+(4096+1024)]=7,667,712（约 7.67M）。

对 q,k,v,o 全加 LoRA：36×16×[(4096+4096)×2+(4096+1024)×2]=15,335,424（约 15.34M）。
首轮 35M 属计算失误，现正式更正为 15.34M。

读出头参数未实计：补充 4096→128→1 二元读出头参数实计：4096×128+128+128×1+1=524,545（约 0.52M）。基座 8,767,123,696 + LoRA 15,335,424 + 读出头 524,545 = 8,782,983,665（约 8.783B），距 9B 上限保留约 217.02M 冗余，符合硬约束。

撤销臆造的固定资源硬门：撤销“38GiB、3.0 fps、6 小时”等无项目实测依据的固定门槛；执行阶段应在非测试长样本上实测动态显存峰值与耗时，而非预设死板指标。

纠正数据比例与测试覆盖假设：68.4%（119/174）是初赛测试集 16:9 画幅分布，复赛 426 个样本的实际比例尚未读取；撤销“将线上覆盖率从 41% 调至 60%”的线上阈值搜索建议。

纠正空间训练与多段矛盾表述：撤销“仅微调中心点位移”的矛盾说辞，空间端严格冻结未微调 8B 基座；撤销“强制聚合 1 至 5 段”，时序端支持自适应多段与合法空预测。

三、对其他席位观点的具体交叉批判
1. 批判 sol（ChatGPT 5.6 sol）

制造虚假前置条件与死锁：sol 坚持“必须证明 4B 出现明显容量瓶颈，才准启动 8B”。在 4B 时序文本 SFT 模式已在 R7 明确遭遇结构性瓶颈的前提下，穷举 4B 超参去“证明瓶颈”的算力与时间成本远高于直接做 8B 小规模参数/显存探针。用户已明确表达 8B 倾向，机械压制 8B 违反敏捷决策原则。

凭空捏造无依据门槛：sol 提出“recall 至少提升 3 个百分点，F1 不允许退化超 1 个百分点”。在 104 条弱开发集上，未经过 bootstrap 方差检验即设定固定百分点门槛，属于主观臆断。

输出头设计脱离数据事实：sol 建议同时输出“前景概率、高光重要性、边界偏移”。一手数据仅有二值弱区间，根本没有连续级高光重要性（saliency）真值，强行构造所谓重要性头只会迫使模型拟合人工捏造的平滑曲线。

2. 批判 Grok

一手文献数字存在事实性跨列错误：核对 Moment-DETR 原文（NeurIPS 2021，arXiv:2107.09609）表 4 与表 9，移除 saliency loss 时，验证集 R1@0.5 是从 53.94 降至 44.84；R1@0.7 是从 34.84 降至 25.87。Grok 称“R1@0.5 从 44.84 掉到 25.87”，明显将两列不同 IoU 阈值的实验结果混淆拼接。

虚构“线上噪声带”：Grok 建议“连续两个官方差值落在预先写下的噪声带就停线”。官方 Evaluator 为黑盒，测试集仅提交过两次，没有任何方差统计先验，凭空设定“噪声带”属于伪科学，应修正为预登记的“最小工程决策差值”（如 ΔF≥0.3）。

3. 评析 Tibo

Tibo 正确指出了“时间读出必须置于完整视频窗口之后，确保经过 LoRA 层且具备完整时序上下文”的关键架构设计；但其建议的候选中包含“8B 区间文本 SFT”，这在初赛与 R7 已被证伪，无需再为无效机制浪费 8B 算力。

四、核心争议裁决与论证
1. 8B 探索时机：支持立即执行小探针

无须等待 4B“容量瓶颈证明”。首批即可在 CPU 合同就绪后，启动单卡 8B 非测试长视频显存/吞吐探针（仅验证 forward 显存与速度，不训练）。8B 具备更强的跨模态通用表征能力，只要参数量合规且显存不 OOM，尽早获得其工程真实成本是最优解。

2. 共享 8B 架构：时间 LoRA + 4096→128→1 读出头可行性

因果与泄漏边界：时序查询 Token（例如词表内预置时间标记）必须严格排在视频全部帧 Token 之后。前向计算时，视频 Token 提取全时序上下文，后置查询 Token 通过因果注意力聚合上下文后，经由共享 MLP（4096→128→1）映射为固定 PTS 网格上的 logits。严禁将真值区间注入 Prompt，保证严格的时间单向因果，彻底杜绝未来帧泄漏。

训练对齐：仅激活语言主干 q,k,v,o 的 rank-16 LoRA 与该读出头，视觉塔与基础权重完全冻结。反向传播时，BCE 损失仅通过 LoRA 梯度回传，避免扰乱底层视觉特征。

空间调用隔离：在空间裁剪阶段，彻底将 Adapter scale 设为 0 并分离读出头，恢复为未经微调的 8B 基座原生定位调用，搭配已验证的镜头门与插值工程链，确保空间能力不受时序训练侵蚀。

3. 未知时间 Mask 与 Query-free 负例边界

AIC 无自然语言 Query，不能照搬 Moment-DETR/UniVTG 的跨模态匹配负例。

严格划定三态：

弱教师标注的正例区间内的网格记为 1；

标注片段内、正例区间之外的明确背景时段记为 0（有效负例）；

源视频中未被该片段标注覆盖的时段，统一赋予 UNKNOWN_MASK，Loss 权重置 0，不参与反向传播。

此举既保留了对高光边界的辨识约束，又避免将大量未标注的潜在真实高光误杀为负例。

4. 阶段止损线

离线止损：在 5 折来源组交叉验证中，若 8B 稠密打分模型的召回率低于 P2-T2 且 F1 发生明显退化（ΔF1<−0.01），立即终止 8B 训练，切回 4B 分支；

线上止损：若线上探索包较基线包波动小于预登记的实用差值（∣ΔF∣<0.2），停止线上碰运气，退回离线定位。

5. 最强反例

8B 的大容量极可能将弱教师标注中的边界抖动与假负例“学得更加笃定”，同时 8B 基座对非常规画幅（如极端 16:9 裁剪）的空间先验可能发生漂移；加之 8B 前向计算耗时大幅增加导致空间锚点被迫稀疏化，最终导致线上联合分反而低于轻量稳定的 4B 基线。
