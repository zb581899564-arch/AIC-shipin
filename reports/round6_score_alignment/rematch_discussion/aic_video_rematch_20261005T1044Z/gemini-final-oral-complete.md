四、核心争议裁决与论证
1. 8B 探索时机：支持立即执行小探针

无须等待 4B“容量瓶颈证明”。首批即可在 CPU 合同就绪后，启动单卡 8B 非测试长视频显存/吞吐探针（仅验证 forward 显存与速度，不训练）。8B 具备更强的跨模态通用表征能力，只要参数量合规且显存不 OOM，尽早获得其工程真实成本是最优解。

2. 共享 8B 架构：时间 LoRA + 4096→128→1 读出头可行性

因果与泄漏边界：时序查询 Token（例如词表内预置时间标记）必须严格排在视频全部帧 Token 之后。前向计算时，视频 Token 提取全时序上下文，后置查询 Token 通过因果注意力聚合上下文后，经由共享 MLP（4096→128→1）映射为固定 PTS 网格上的 logits。严禁将真值区间注入 Prompt，保证严格的时间单向因果，彻底杜绝未来帧泄漏。

训练对齐：仅激活语言主干 q,k,v,o 的 rank-16 LoRA 与该读出头，视觉塔与基础权重完全冻结。反向传播时，BCE 损失仅通过 LoRA 梯度回传，避免扰乱底层视觉特征。

空间调用隔离：在空间裁剪阶段，彻底将 Adapter scale 设为 0 并分离读出头，恢复为未经微调的 8B 基座原生定位调用，搭配已验证的镜头门与插值工程链，确保空间能力不受时序训练侵蚀。

AIC 无自然语言 Query，不能照搬 Moment-DETR/UniVTG 的跨模态匹配负例。

严格划定三态：

弱教师标注的正例区间内的网格记为 1；

标注片段内、正例区间之外的明确背景时段记为 0（有效负例）；

4．日内流程

**批次开始前：**核当天余额，选出已就绪的 1–5 个候选，登记唯一变化、证据等级、资源预算、代码/权重/配置哈希。A 不需要等尚未训练出的 C 的权重哈希；但每个候选必须在获知其自身成绩前冻结，在同一比较批次里不能边看分数边改下一行。

## 7. 采用、拒绝与保留异议

采用早基线、立即有界 8B 工程小试、可信负格准入、二元头、共享空间及有价值的五次整包比较。拒绝直接全参/RL、虚构 saliency、强制非空/1–5 段、固定显存/fps/六小时门、初赛覆盖率推复赛阈值、线上反演标签，以及为消融形式必做四种训练。

保留 Grok 的 4B 优先异议：如果 8B 真实排队/吞吐/空间成本挤掉高价值候选，依据机会成本回退 A。最强反例是 8B 更好模仿有偏教师、弱分涨，同时原生 8B 空间弱于 4B，官方整包仍下降。mask、梯度与隔离验收均不能排除它。

一手论文已核的方法与关键差异：

- [Moment-DETR](https://proceedings.neurips.cc/paper_files/paper/2021/file/62e0973455fd26eb03e91d5741a4a3bb-Paper.pdf)：选择监督有作用；query 条件负例不能直接迁移。原表跨列错误已纠正。
- [UniVTG](https://arxiv.org/html/2307.16715v2)：稠密表示值得验证；本题没有现成三头监督，420万并非全CLIP伪标签。
- [TempSamp-R1](https://arxiv.org/html/2509.18056v1)：F2与WMSE奖励不含AIC裁剪IoU，本轮不据此启动RL。
- [SVHighlights](https://arxiv.org/html/2606.06926v1)：排序/覆盖口径不同；其多个8B及ASR完整链超过本题参数预算。
