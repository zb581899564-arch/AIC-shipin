## 主控独立初始意见（读取普通参与者回复之前）

我愿把用户偏好的“接近9B微调”升级为优先候选研究主线：8B共享主干、时间LoRA/轻头与基础空间任务隔离，先取得具体参数账和非测试小规模成本；4B/P2-T2保留回滚与独立对照，不要求先花几天完成小4B路线才碰8B。

我的机制优先是短窗口重叠、真实PTS固定网格时间打分/事件边界建模，而不是只把原区间文本SFT扩大到8B再多训。弱标签训练采用覆盖mask，未标注源时间不作负样本；保留空、多段、完整事件和损失对齐。用来源隔离和低成本有限验证发现明显退化，但不用弱F1上涨自称可预测线上；是否必须bootstrap下界>0作为每个探索包硬门，允许重新讨论，不能后验改旧协议。

支持把五次机会用于少数有明确新假设、能重现的完整候选比较，尽快让真实基线获得复赛官方分，而不只做研究不交包。初始倾向预登记2–3个机制不同且工程完整的方案，允许风险候选披露离线证据不足；不建议每天扫阈值/覆盖率。其理由包括规则不确定性与总分归因不可辨识，不是说任何分数反馈天然违法。不要向外部AI发送测试内容。

若论文有query，必须指出AIC输入没有用户自然语言query；通用高光提示≠QVHighlights人工query和query相关saliency。不能把检索论文的mAP或saliency AP直接当AIC联合F，也不能把该数据的未标注时段全当真负例。RL/DPO只在奖励/偏好真实可信且SFT瓶颈明晰时作为后续，不默认昂贵RL。

最大反例：更大模型可能只更忠实模仿有偏弱教师；稠密打分可能把有偏边界变成更有把握的错选；共享8B又可能损坏空间能力并增加全量空间调用成本。这些必须通过匹配方案与真实输出验收来否证，论文不能代替本题证据。

## 4. 评分与实验协议

单视频 `F = 2ΣIoU/(Npred+Ngt)`；双方为空为1，单方为空为0。常规合法、有匹配的非空样本可分解为时间帧集合 F1 × 匹配帧平均 IoU；零交集单列，不能除以零。

评分输出至少包含：联合分数、时间 precision/recall/F1、匹配帧平均 IoU、预测覆盖率、空预测率、合法率，以及按视频、来源组、目标画幅和场景的明细。总指标按视频平均，置信区间按来源组配对 bootstrap。抖动作为诊断项，不擅自添加到官方分数。

必须覆盖：双方空、单方空、完全匹配、无交集、部分时间重叠、框比例换算、重复帧、越界框/帧、NaN/Infinity、错误视频ID、缺视频、取整与区间端点。无效项细节缺官方依据时标 UNKNOWN，不私自宣称等价。

在非测试诊断数据上做三组消融：

1. 实际时间 + 实际空间：可部署结果。
2. 实际时间 + 参考框：隔离时间问题的诊断。
3. 参考时间 + 实际空间：隔离空间问题的诊断。

弱参考得到的结果仍为弱参考指标；后两项不能作为部署收益。只改变一个组件以支持归因。

## 二、赛题任务和我们采用的评分理解

### 2.1 输出内容

每个测试视频需要输出若干被选中的帧及其裁剪框。输出同时回答两个问题：

- **什么时候剪：** 哪些帧属于高光；
- **画面裁哪里：** 每个被选中帧对应的主体裁剪框。

测试集共 **174 个视频**：

- 119 个目标比例为 16:9；
- 55 个目标比例为 9:16；
- 按当前测试元数据合计 87,781 帧。

### 2.2 当前掌握的官方评分形式

按现有官方文档，单视频联合指标为：

`2 × matched_frame_IoU 之和 / (预测帧数 + 真值帧数)`

其中：

- 时间上没有匹配到真值的预测帧会增加分母但没有 IoU 收益；
- 真值高光帧漏预测同样增加分母；
- 匹配帧的裁剪框 IoU 决定该帧贡献；
- 双方都为空计 1，只有一方为空计 0。

这意味着时间与空间不能分别优化后简单相加。一个空间框再好，如果对应真值高光帧没有被选中，贡献仍为 0；反之，时间选中但空间框偏离主体，也只能得到较低贡献。

### 2.3 仍未取得的官方信息

截至本报告：

- 官方 evaluator 源码仍未取得；
- 没有官方逐视频、时间分项或空间分项成绩；
- 无法看到测试真值；
- 无法精确计算“时间问题贡献多少分、空间问题贡献多少分”；
- 非法行、重复帧等极端输入在官方 evaluator 中的全部细节仍无法独立确认。

项目内部评分器只能标记为 `INTERNAL_SPEC_REIMPLEMENTATION`，不能冒充官方评分器。

### 3.2 原始训练标签

该 518 条清单要求：

这套条件适合时空联合诊断，却不应未经复核直接当成纯时间模型的唯一数据池。

### 3.4 新发现：时间训练池可能被不必要地缩小

本轮在不读取比赛测试内容、不启动训练的前提下，对原始 987 条标签做了结构性时间资格扫描：

| 项目 | 数量 |

| 拟 dev | 140 条 / 124 组 |
| 拟 holdout | 119 条 / 103 组 |
| 有 ROI | 573 条 |
| 无 ROI但可能有时间监督 | 335 条 |

| missing source | 75 条 |
| 时间段结构非法 | 3 条 |

该结果只能标记为：

`STRUCTURALLY_ELIGIBLE_TEMPORAL_ONLY_PENDING_PTS_AUDIT`

- 媒体身份；
- clip 起点；
- 容器 PTS；
- 帧序与秒数的转换；
- 来源组是否真正隔离。

此外，`temporal_pool_opportunity.json` 已经列出了这 908 条记录及初步 split 字段，因此其中的 119 条“拟 holdout”不能再称为盲留出。后续若采用这批数据，只能把切分冻结为 `FIXED_WEAK_DIAGNOSTIC_ONLY`，或者使用预先登记的来源组交叉验证；不能声称得到了新的人工盲测集。

但它证明了一项重要设计问题：**P2-T/P2-T2 的纯时间训练沿用了空间标签的筛选门，370 条训练记录可能只是可用时间监督的一部分。**

## 五、各阶段做过什么、得到了什么

### 5.1 数据对齐与第五轮

- 37,325 帧使用同帧旧框；
- 3,243 帧使用“最近旧框”复制；

- 95.7% 的复制来自旧空间覆盖区边缘。

因此第五轮解决了一部分“什么时候剪”，却没有为新选中的时间区间真正补齐同帧空间预测。

### 5.2 OraRL 四轮调查

OraRL/Video-ORA 路线经过协议、合成真值、公开图片和弱标签对照：

- 跟踪输出经常把初始化框原样复制；
- 在精确运动合成真值上不优于固定首帧框；
- 逐帧独立空间定位有位置响应，但小目标尺度偏大；
- RefCOCO 小样本说明图片定位接口有效，但不能代表 AIC；
- 在固定弱代理对照中，OraRL 直接定位和“描述+定位”均落后当前 Qwen 基线，且抖动更大。

结论：**OraRL 不适合直接接管当前裁剪链路。** 若没有新假设和独立真值，不应重复前四轮实验。

### 5.3 空间 LoRA 小试验

## 八、归因判断：证据等级与置信度

### 8.1 第一主因：时间选择过窄、弱正例召回不足

**置信度：中高。** 时间集合收缩和非测试召回证据很强，但官方没有提供逐视频或时间分项，因此不能把它升级为已直接观测的官方主因。

证据链：

- 测试预测覆盖从 43.48 候选的 76.20% 降到 41.40%；
- 新候选相对旧候选删除 32,705 帧，只新增 2,160 帧；
- 130/174 个视频的新时间集合是旧候选子集；
- P2-T2 开发召回 0.6057，低于 BASE 0.6328；
- 弱正例命中 172/272，低于 BASE 179 和 OLD_S2 191；
- P2-T2+QWEN 相对 BASE+QWEN 的弱正例联合增量区间跨 0；
- 线上只增加 0.46，与“更高精确率但损失召回”的预期相符。

不能据此断言 43.48 候选的所有额外帧都是真高光。它可能也包含很多假阳性。但当前证据表明 P2-T2 的收缩幅度大，而非测试证据没有证明这次收缩在联合指标上是最优的。

### 8.2 第二主因：时间训练池被空间准入条件压缩

**置信度：中高。**

证据链：

- 原始 987 条全部有时间段；
- P2-T2 只训练 370 条；
- 当前联合清单要求 ROI 和可注入空间映射；
- 初步发现 908 条可能具备纯时间结构资格，其中 335 条没有 ROI；
- 时间任务本身不需要 ROI；
- 当前模型仍在召回上偏弱。

限制：

- 908 条尚未经过完整 PTS 和媒体身份审核；
- 不能保证扩大数据后一定提升；
- 仍需来源组冻结和交叉验证，防止把错误标签量变成更大的噪声。

### 8.3 第三主因：空间模型相对旧候选缺乏足够新增能力

**置信度：中高。**

证据链：

- 共同帧新旧框平均 IoU 0.9384、中位数 0.9804；
- 全部采用最大合法宽度，尺度自由度没有被使用；
- 86.06% 的框由锚点插值产生；
- 训练弱空间标签全部为 9:16 固定 169×300；
- 测试集 68.4% 是 16:9，训练标签无法直接验证其构图偏好；
- 空间 LoRA 小试低于未微调 Qwen；
- OraRL 替换也已失败。

### 8.4 第四因素：训练目标与官方联合指标仍存在代理偏差

**置信度：高。**

这是指标公式的直接结果。P2-Final 空间端比第五轮更可靠，但如果时间模型没有选中相应真值帧，空间改善不会计分。共同帧的框又与 43.48 候选高度相似，因此大幅删帧后的净收益只剩 0.46 是合理现象。

## 阶段 M2：优先验证稠密时间打分（主要改进）
