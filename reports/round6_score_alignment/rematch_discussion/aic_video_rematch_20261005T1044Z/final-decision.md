## 1. 选定主案与后备

**主案 C：共享 Qwen3-VL-8B-Instruct + 时间 LoRA + 后置查询二元网格头。**基础及视觉权重冻结，文本 q/k/v/o 使用 rank16 LoRA；查询在完整窗口视频之后，从 processor 展开后的真实 token 位置读最终隐状态，接 4096→128→1 共享头。首版仅覆盖感知 BCE，不同时叠排序、精彩等级、边界头或 RL。

空间使用同一个 8B，真正禁用时间 adapter/头，清缓存并验恢复；保留源时间固定镜头/锚点、同帧身份与有界插值。不能将独立 8B 时间与 4B 空间拼接，即使串行也必须合计参数。

**A：完整 4B/P2-T2 链先行形成复赛基线，也是唯一交付后备。**不等待 C 训练完成。A 保持历史配方，旧非空/段数约束须如实披露；不能把新 C 的合法空功能写成 A 已验证能力。新链分别记录合法空、解析失败、推理失败，不能把失败转换为空。历史代码不回写。

配置推算：基础 8,767,123,696 + LoRA 15,335,424 + 小头 524,545 = **8,782,983,665**；距十进制 9B 余 217,016,335。实际加载验收尚未做，须计全链所有逻辑参数、冻结参数、辅助模块和共享关系；量化不降低统计参数量，避免复制 embedding/lm_head。[模型配置](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct/raw/0c351dd01ed87e9c1b53cbc748cba10e6187ff3b/config.json)、[赛题规则](https://www.aicomp.cn/tracks/tracks-6/4267.html)。

8B 区间控制 B、4B 稠密控制 D 都不是首批必做；确能改变决策且成本可接受时才另登记。A/C 比的是完整配方，空间基座也变化，不能叫纯规模消融。

## 2. 正式训练前最关键的数据门

先审已有生成记录、使用依据和教师任务：教师究竟完整评了哪段时间、是否只选有限片段、是否截断、未选是否可解释为通用高光负例。clip 起止/PTS 通过不等于已证标注穷尽。

- 有明确选择与可解释未选语义：分别标为 WEAK_POSITIVE / TEACHER_NEGATIVE，仍属弱监督。
- 正例之外未证明完整观察/标注的范围：UNKNOWN，直接损失置零。query 不相关不等于通用高光负例。
- 跨观察边缘格先 mask；完整格可用已知弱正帧占比作为 BCE 目标，这是帧二值标签的聚合，不是虚构精彩等级。
- 没有可解释负监督：**停止 C 正式二分类，也不换同监督的 4B 头绕过**；保留工程探针，A 独立推进。A 自己的数据使用依据也须核。

首个工作日有界审计，48 小时仍无负监督依据就不启动正式 BCE；不重跑已完成的 908 条 PTS 审计，不重切 704/104/100 外层来源划分，不默认要求用户补标。独立 query-free 桥接存在则有限检查，缺失就披露盲区；弱正例关键帧不能测未知段召回。

## 3. 工程与质量验收

先做非测试标签→网格→源帧回放，量化短事件和边界损失。32s 窗/16s 步/2s 格只是草案，训练前用非测试证据冻结；实际源 PTS、端点、padding、截断与真实 query 索引必须一致。

工程探针要有数个有效 forward/backward/update，证明头与 LoRA 都在学习、基座和视觉不更新。冻结 embedding 与不当 reentrant checkpoint 可能让 LoRA 无梯度而头仍降 loss；优先按安装版本核 use_reentrant=False。首步 LoRA A 零梯度可能正常；全 UNKNOWN 累积批次跳过 optimizer/scheduler 有效更新；固定输入仅改 masked 标签时 loss/梯度不变。检查视频错配诊断和空间 adapter-off 恢复。[PyTorch 依据](https://docs.pytorch.org/docs/2.9/checkpoint.html)、[LoRA 初始化](https://huggingface.co/docs/peft/developer_guides/lora)。

参数、许可、来源、时间/帧身份、梯度、隔离和最终 426 条输出完整性是必过门；缺失、重复、非法框或静默跳样本阻断候选。官方 evaluator 未取得，内部评分器继续标 INTERNAL_SPEC_REIMPLEMENTATION。

弱评估区分 covered weak 指标与全源指标。新报告给视频宏点估计，来源组重采样区间；保留旧组宏数值，不能与新视频宏直接相减。训练组内登记校准划分，正式 104 条比较前冻结阈值/checkpoint；100 条一次性弱确认不称人工盲测。

明显塌缩、系统性失败或配对弱 F1 区间全负且无独立取舍依据：停该版本。工程全过、区间跨零、无明显系统性失败且有机制依据：可披露风险后有限官方验收。召回略降并非必然失败；也不把弱分涨写成官方提分。

## 4. 每天五次：主动试分的具体矩阵

官方每日 5 次、按复赛阶段最高得分认定；正常调试可以比较合格整包，预登记不替代组委会对特殊自适应搜索的解释。总分能给整包排序和处理效应，不能唯一反演隐藏时间标签/框真值。[复赛通知](https://www.aicomp.cn/notice/notice-3/5307.html)。

最小必需是 A 和 C-O8。C 准入后，同一 checkpoint 可形成以下受控矩阵：

| 包 | 时间处理 | 空间锚点最大间隔 | 用途 |
|---|---|---|---|
| A | 冻结 4B/P2-T2 | 原完整 4B 链 | 尽早取得复赛基线，不每天重复 |
| C-O8 | 32s 窗、16s 步，重叠聚合 | 8 帧 | 主案整包 |
| C-N8 | 同权重/格/阈值，32s 不重叠窗 | 同 O8 空间场 | 重叠处理对照 |
| C-O4 | 同 O8 时间处理 | 4 帧 | 插值精度/成本对照 |
| C-N4 | 同 N8 时间处理 | 同 O4 空间场 | 两项处理交互 |

4/8 帧和窗口方案需先有非测试边界、插值误差与成本依据；未通过则删除对应候选。相对逐帧 Qwen 的一致性仍不是相对真实构图精度。有 5 个有意义且合格的包可以用满 5 次，只有 2 个就用 2 次，不设人为每天 1–2 次上限。

日内先核余额，冻结当前批次的唯一变化、证据和配置；每包成绩可见前记录代码、权重、JSONL/ZIP SHA256。同批不能边看分数边改下一行。A 不必等待尚未训练的 C 权重哈希。成绩返回后保留任何更高有效包，决定哪些已有配方值得复现；不生成阈值邻居、目标覆盖率或逐视频探针。下一批有新的独立非测试依据再登记。批次没有超过保留包，停止该版本邻域扫点，不虚构 0.2/0.3 分噪声带。

同身份/同模型/同源帧/同空间合同的结果可受控复用；不能跨 4B/8B 复用框，不能用初赛旧框填新帧。空间锚点先按源视频定，避免候选选中起点改变共同帧框。

## 7. 采用、拒绝与保留异议

采用早基线、立即有界 8B 工程小试、可信负格准入、二元头、共享空间及有价值的五次整包比较。拒绝直接全参/RL、虚构 saliency、强制非空/1–5 段、固定显存/fps/六小时门、初赛覆盖率推复赛阈值、线上反演标签，以及为消融形式必做四种训练。

保留 Grok 的 4B 优先异议：如果 8B 真实排队/吞吐/空间成本挤掉高价值候选，依据机会成本回退 A。最强反例是 8B 更好模仿有偏教师、弱分涨，同时原生 8B 空间弱于 4B，官方整包仍下降。mask、梯度与隔离验收均不能排除它。

一手论文已核的方法与关键差异：

- [Moment-DETR](https://proceedings.neurips.cc/paper_files/paper/2021/file/62e0973455fd26eb03e91d5741a4a3bb-Paper.pdf)：选择监督有作用；query 条件负例不能直接迁移。原表跨列错误已纠正。
- [UniVTG](https://arxiv.org/html/2307.16715v2)：稠密表示值得验证；本题没有现成三头监督，420万并非全CLIP伪标签。
- [TempSamp-R1](https://arxiv.org/html/2509.18056v1)：F2与WMSE奖励不含AIC裁剪IoU，本轮不据此启动RL。
- [SVHighlights](https://arxiv.org/html/2606.06926v1)：排序/覆盖口径不同；其多个8B及ASR完整链超过本题参数预算。
