# v6 全链工程修复与未放行的科学门

用户要求全面核查、发现问题立即解决。本版本集中修复 v5 后续尚未触发的工程问题；旧 v5 原始回答、逐窗成功、12/12 全正小试 STOP 与冻结源码不改。

教师标签保留原始数值。学生序列化和生成 grammar 从四位小数扩展为最多十八位有限十进制，必须经过严格 float 数值身份复核，不裁数、不四舍五入；训练目标、弱开发、生产显式绑定同一套 helper，避免旧 common.py 重排搜索路径后混用四位规则。原 128/32 输入与原 validator 保持，不生成合成训练标签。

开发和生产共享原生 PTS 的半开区间实帧可实现性检查。解码保留窗口中全部真实源帧 PTS，而不是只依据 64 个提供采样点；正区间若没有实帧，保留原输出和被拒绝区间，显式失败，绝不转为空预测。

完整标注新增磁盘估算仅使用两个实测探针的逐窗字节，扣除已有标签；原小试目录总量不再被当成两窗成本。空间成本优先用当前 T NONTEST8 的真实模型调用耗时；合法全空回执不含模型耗时，不进入算式，必要时使用同固定 8B 历史非测试实测或明确报出缺失。

probe/all/review/labels 各保留独立 server session 的日志、PID、models 与停止回执。要求新生成的重输入探针不能静默拿已有 done 缓存冒充。原标注 schema 的 all_provided_frames_reviewed=true 是 grammar 常量，只是结构字段，不能宣称是模型自主确认；第二弱复查仍保留可拒绝的真实 boolean。

v5 语义诊断已出现把合法窗口内秒数再次减去源 PTS 的拒绝理由。v6 复查提示词增加源/窗口两列数值对照，不修补原标签；它只纠正坐标说明，不能认证高光价值或代替语义审核，旧拒绝仍保存。

**v5 的十二窗仍无真实空例，微调尚未获科学准入。** 本版本 config.launch_admitted=false；工程 CPU 验证通过不解除分布/语义门，不重跑已知失败的整套全量。独立 teacher_semantic_diagnostic_v1 继续取具体证据，下一项科学配方须另行登记。T 更新仍0，暂无新 T ZIP，不给未经证据的完成时间。

Mac 不参与，固定模型原地使用，实际容量和共享锁/账本保持。100confirm 不读；所有中间产物与最终单个 ZIP 留 Linux，新大流量传输先说明并取得许可。只有426独立 strict、大小/SHA/CRC 与根 completion PASS 才能称为可提交。
