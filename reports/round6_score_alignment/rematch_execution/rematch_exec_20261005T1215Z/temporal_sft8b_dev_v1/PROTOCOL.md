# Linux8B 固定开发比较与生成包授权

用户要求“生成一下包中”，本轮主控按已完成 Linux8B 最终 adapter 准备下一份复赛候选。官网上传未授权，Mac full 继续原协议。

开发协议沿用全量训练前已冻结的 dev_protocol.json：原104视频/96来源组、两臂固定8B基座与最终5epoch adapter、原R7提示词/processor、全部非重叠30秒窗口、确定greedy/256token输出、来源组10000次bootstrap seed20261006。实际112窗口，两臂共224次生成；最终模型只评一次。确认100条不读取，不选择epoch，不改阈值。

单窗口保留MODEL_OK、EMPTY_UNSUPPORTED、PARSE_FAILURE和INFERENCE_FAILURE，失败窗口不制造空的合法预测；有效窗口合并回完整clip-local时间，104视频全部保留在弱教师指标分母中。未知范围不成为认证负类。本来提示词不支持合法空，因此合法空率为0，同时单独报告空输出率。

运行前将既有停止条款落实为可执行条件并冻结：任一推理工程失败、最终全输出无效、最终所有弱正例重叠为零、来源组F1配对95%区间上界小于0均STOP。没有独立证据支持用其他收益绕过全负区间。零散解析失败不删除，作为合法率结果单独记录；比赛生产入口仍要求所有窗口通过。此比较只是WEAK_TEACHER_AGREEMENT_INTERNAL_SPEC_REIMPLEMENTATION，不能承诺官网提分。

数据源原字节与早期标签加工关系未全部确证；现在绑定当前字节并核真实源总帧/FPS、选中数值时钟与processor patch时间，不能写成原加工身份已全部补齐。无外部数据/API、无新增权重/媒体下载、无额外4B模型。

评估与后续阶段使用已有共享gpu_run.py、GPU锁与追加账本；累计不限、旧7200秒偏移保留。合计Linux工作区与整个Mac唯一工作根及剩余已登记Mac产物、新产物不能超过80GiB。初次单评估止时14400秒为保守完整作业上界，后续空间按真实锚点数量与新8B测量另登记。

源码、输入、基座全部文件、最终adapter与训练报告均先CPU字节核验，admission.json逐文件冻结。运行中不改已绑定文件，不重复launcher。开发门过后，先同8B基座的非测试联合完整工程验收，再426复赛时间/CPU调度、按实际锚点另准入8B原生空间、合成严格ZIP。禁止复用4B测试框冒充8B空间、失败转空/删源以及官网自动上传。
