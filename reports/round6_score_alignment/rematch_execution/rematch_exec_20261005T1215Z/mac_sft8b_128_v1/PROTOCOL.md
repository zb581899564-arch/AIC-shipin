# Mac 8B / 128 帧独立版本

用户授权原文：mac微调模型不应该更有优势？mac再去微调一个版本怎么样。

Mac M5 Pro / 64 GiB 的统一内存提供更大的工作集空间，质量收益与速度均需实测。Linux 64 帧完整训练继续运行。此次 Mac 版本采用相同固定 8B 基座与训练来源，增加到每个 30 秒窗口最多 128 帧、序列上限 16384；同时改变了硬件后端和解码器，因此结果是整体候选比较，不能单独归因于帧数或 Mac。

## 数据与监督

- 基座 Qwen/Qwen3-VL-8B-Instruct，revision 0c351dd01ed87e9c1b53cbc748cba10e6187ff3b，模型全部 15 个原始文件逐项 SHA-256 验证。
- 原始 R7 train 704 条、602 来源组，形成 724 个已知正例窗口；与 Linux 完整训练的清单字节相同。原始 104 条 dev、100 条 confirm 的来源隔离保持。
- 标签是历史教师弱标签。目标仍为 assistant 区间 JSON 的 CE；未选范围为 UNKNOWN，30 个无已知正例窗口继续排除，未创造负类 BCE 目标，也未获得正式 C 的准入。
- 只复制登记的 704 条 train 来源与固定模型，不复制复赛测试媒体或测试标签，不调用外部模型/API。
- PyAV 顺序解码；按固定 CFR 帧序号抽样，核实际 FPS、声明帧数、选中帧 PTS 与来源时钟；保持原 R7 一帧近似 CFR 门。未声称与 Decord 像素逐字节相同或具备原生精确 PTS 合同。
- 14 个历史源终点仅允许原注册证据中的毫秒舍入差（0.000500001 秒内）；不改旧标签，不扩大一般边界容差。

## 冻结训练

PyTorch 2.5.1 / torchvision 0.20.1 / transformers 4.57.1 / peft 0.17.1，BF16 / MPS / SDPA。沿用非重入 gradient checkpointing，不允许隐式 CPU fallback。

语言注意力 q/k/v/o 的 144 个模块使用 r16 / alpha32 / dropout0.05 LoRA。冻结基础和视觉参数，无辅助头、modules_to_save 或独立 4B 叠加。基础 8,767,123,696 + LoRA 15,335,424 = 8,782,459,120 参数。若将来使用空间组件，必须恢复同一基座并关闭时序 adapter，重新验证整个部署链总参数 <=9B。

5 epochs、grad_accum16、lr5e-5、seed20261006、AdamW betas(0.9,0.999)、eps1e-8、weight_decay0、clip_norm1、无 scheduler。每个 epoch 独立固定种子打乱，最终 3620 个有效样本 / 227 次更新；最后四样本按 4 归一化。只保存最终 adapter，不选择中间 epoch。

## 执行与停止条件

1. 在唯一 Mac 工作目录下建立独立环境、验证完整资产、真实 lossless codec / processor / 掩码 CPU 检查 8/8。
2. 登记 20 个 train 窗口探针（原 17 个工程窗口加 3 个按训练元数据选择的长/多段窗口），运行 3 次更新 / 48 个有效样本，最多 10800 秒。要求真实有限 loss、连通有限梯度、LoRA 权重更新、完整基础/视觉参数字节冻结、adapter 重载后 144 模块 / 288 张量字节一致。
3. 仅探针完整 PASS 才登记全量运行。完整训练从固定基座和全新 LoRA 开始，不接续探针 adapter。全量 wall bound = ceil(probe_wall_seconds / 48 * 3620 * 1.75 + probe_wall_seconds)，按实测成本估算并留余量。
4. 共用 Mac 工作根的 advisory GPU lock，启动前与运行中核活动计算、实际工作占用和预计产物；外部计算出现即停止本次自有子进程，绝不终止外部任务。累计 GPU 时间不限，Mac 实际耗时另追加登记，Linux 的 7200 秒偏移及历史账本不改写。
5. 80 GiB 占用边界按 Linux 当前占用加已登记输出上界、Mac 工作根当前占用加本阶段预计产物保守合计。容量错误、哈希变化、合同失败、MPS 不支持、非有限梯度、冻结或重载失败均 STOP，不静默改 batch、精度、帧数、数据、loss 或 CPU fallback。
6. 传输经已验证的 Linux–Mac Tailscale 直连。临时传输工具只绑定 Linux Tailscale IP、只允许 Mac IP、要求随机 capability，读取白名单文件；完成、失败或 12 小时截止后关闭自己的发送进程。旧失败桥接、部分文件和日志保留。

## 验收与下一边界

工程完成不表示高光质量通过或官方提分。后续双方只比较固定 R7 dev 104 条 / 96 来源组，使用同一非测试部署评估与弱标签组宏指标、合法率和配对区间；不根据本轮开发结果再调当前训练，不选择中间 epoch，不把弱标签指标当官方得分。confirm 与复赛测试、联合空间验证、推理封包、正式上传均须各阶段单独登记，当前后台入口到完整训练结束为止。
