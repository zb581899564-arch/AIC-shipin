# P2 v2 总控复验（2026-09-18）

**裁决：`PARTIAL_DEV_EVIDENCE_ACCEPTED; P2_FREEZE_NOT_ACCEPTED`。** v2 源帧映射、已运行的开发集推理和预算补记可以作为有效的部分实验记录；`READY_FOR_SUPERVISOR_REVIEW` 只是执行方状态，尚不能升级为完整 P2 交付验收，更不能用于比赛提交或提分推断。本复验不运行 GPU、不读取比赛测试集、不打包或上传。

## 独立确认的事实

- 33/33 单元测试通过。上一版总控给出的两个绕过样例现在都被拒绝：未设距离上限时返回 `NEEDS_INFERENCE`；审计上限 100 帧而门控上限 1 帧时，距离 89 帧的复用返回 `NEEDS_SPATIAL_INFERENCE`。
- 逐文件验证 v2 冻结清单中**已列出**的代码、输入和 JSON 证据哈希均匹配。训练机与本地 v2 请求、输出、运行元数据的 SHA-256 相同；训练机当前没有计算进程或活动作业文件。
- 独立按 S2 原始段、`clip_start_sec` 和 `source_fps` 重建源帧选择：13,777 个键与完整请求清单完全一致。冻结的 272 个标签帧都满足既有 `round((clip_start + clip_frame/clip_fps) * source_fps)` 映射。6,186 个子集键均属于完整选择，6,000 个新推理、186 个同帧控制；6,186 条推理输出逐键对应，0 缺失、0 重复、0 无效标志。
- 逐行独立复核 82 条开发集合成记录：6,186 个框都在选择集合内、无重复、几何合法，与对应模型输出或钳制后的弱 ROI 一致；7,591 个选中帧**没有框**。合成文件 SHA-256 与 m2f 记录一致。其“严格校验通过”仅说明**已输出的稀疏行**格式合法，并不说明整段选择已完整覆盖。
- 对训练机两条开发视频抽查指定源帧：OpenCV 随机 seek 与从头顺序解码像素完全相同（帧 2287、3843，均值绝对差 0）。这支持本轮修正的源帧解码路径，但不是全部 6,186 帧的逐帧身份核查。
- 从原始 186 个控制帧预测与弱 ROI 独立重算：弱 IoU 均值 0.7543244847、中位 0.8380748767、29 帧低于 0.5、70 来源组；仅是 9:16 弱标签诊断，不能与 272 帧旧基线直接作配对提升结论。
- 两条 GPU 补记与各自日志、请求、输出、run.json 的哈希一致，合计 4,491.78 秒。加在上一轮已验收的 51,993.0795 秒后，估计项目累计 15.69024 小时；原始 GPU 调度账本仍只有 73 行、没有这两个作业，补记不能冒充原调度日志。

## 仍阻断 P2 冻结的事项

1. **门控仍未真正逐行核实来源。** `CoverageGate.judge` 对 `SAME_FRAME` 只看状态，未核对框非空、`source_frame == frame`、`distance == 0`；对 `SHOT_NEAREST` 只看记录的距离与框非空，未核对 `distance == abs(frame-source_frame)`、源帧与目标帧都在同一声明镜头、`crosses_shot_boundary == false`。可复现：构造 `SAME_FRAME` 行（框为 null、来源帧 9、目标帧 10）或 `SHOT_NEAREST` 行（目标 90、来源 1、镜头 `[80,100)`、伪报距离 1），现版门控均返回 `DELIVERABLE`。普通 `audit_frames` 生成的行没有被发现存在此问题；但执行方所称“门控逐行复核来源、距离与策略一致性”尚不成立，需要失败回归测试后修复。
2. **v2 冻结遗漏关键产物。** `round6_p2_freeze_v2_20260918T0310Z.json` 的 16 个 `code_files` 未包含 `remote_infer_gaps_v2.py`、`run_m2f_real_compose_v2.py`，也未包含新加的 `run_m2d_real_compose.py`；最终 `.real_composed_predictions.jsonl` 不在冻结的输入或证据哈希集合中。冻结验证仍运行旧的 `run_m2a_sim_cpu.py`、`run_m2b_boundary.py`、`run_m3_paired.py`，**没有重跑 v2 合成 runner**；其中 m3 使用已作废的 v1 错帧推理文件。m2f 记录自身的哈希可用，但不能替代完整新版冻结。只记 `subset_seed=20260918` 而未保存从 13,777 键确定 6,186 键的生成算法/脚本，也无法重新生成该子集。
3. **交付覆盖尚不完整。** 源帧选择共 13,777，真实模型仅对其中 6,186 帧运行；7,591 帧未推理。合成文件中的另 186 框来自开发集弱标签，部署时不可获得。当前文件只能作为**部分开发集链路检查**，不能称作完整时间—空间推理候选；文件内的 `source` 等审计字段也不能默认当作官方提交字段。P2 剩余约 0.7523 GPU 小时，按执行方实测速率补齐 7,591 帧约需 1.34 小时，不能在现有 P2 限额内继续跑。
