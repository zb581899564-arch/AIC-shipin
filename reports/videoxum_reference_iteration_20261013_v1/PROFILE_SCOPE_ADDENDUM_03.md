# 新参考输入范围与L32的工程筛除

独立新参考沿用此前原B外部验证的每窗最多30秒、64个不同原生帧整数等距采样，真实CPU processor及token预算仍待实际媒体通过后登记。native_profile_01.py是新的通用源时钟/采样模块，没有旧20/5源名、旧根、MAT行数或硬编码视频路径；目前没有实际解码，不把合成检查当真实输入验收。

在这个30秒窗协议下，原始单段不可能达到32秒。因此L32虽然通过部分事实否决，也不能在新参考上产生规则作用，按FOLLOWUP_PROTOCOL_02预登记的至少3来源实际变化门必然不能通过。本次在新模型前将L32标为PROFILE_ACTIVATION_IMPOSSIBLE，不把零变化称质量合格，也不为它另拉长窗口或改阈值。后续只验证已登记的L16；原L8事实失败、L32部分事实通过的历史和登记均保持。

L16是否至少作用于3个开发及3个确认来源，只能由真实原B输出决定，不能为了活跃度按标签或预测换源。映射使用原视频实际PTS与最后帧正duration，不减去猜测时间偏移，不按作者1fps长度造原帧标签；所有原手工秒区间必须落在实际完整视频呈现域。包含非零且无法核实的容器起点则失败。native64 RGB→CPU processor全部实际通过，方可新唯一原B/独立重放/人工代理检查。
